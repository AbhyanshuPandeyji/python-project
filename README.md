# 🧩 User Data Fetcher (Terminal App)

A simple Python terminal application that fetches and displays user data from a public API in a clean, readable format.

This app:
- Uses **no external packages** — only built-in Python modules.
- Fetches data using **HTTP GET**.
- Parses JSON data.
- Displays formatted user details in the terminal.
- Optionally filters users by city name starting with **'S'**.
